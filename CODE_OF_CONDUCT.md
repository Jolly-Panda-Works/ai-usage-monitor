# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, personal attacks and discriminatory behavior are not tolerated.

## Reporting
Report unacceptable behavior to the maintainer through the contact options on [useffarahmand.com](https://useffarahmand.com). Reports are handled privately. Maintainers may remove comments, commits, issues or contributors that violate this Code of Conduct.
