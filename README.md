# AI Usage Monitor

اپ ویندوز برای نمایش لحظه‌ای مصرف، باقی‌مانده و زمان ریست اکانت‌های Claude (چندتایی)، ChatGPT، Gemini و Figma.

## بیلد با GitHub Actions
1. این پوشه را در یک ریپو جدید GitHub آپلود/پوش کن (branch: main).
2. تب **Actions** → workflow «Build Windows App» خودش اجرا می‌شود (یا Run workflow).
3. بعد از پایان، از بخش **Artifacts** فایل‌های `Setup.exe` و `Portable.exe` را دانلود کن.
4. برای ساخت Release خودکار: `git tag v1.0.0 && git push --tags`

## اجرای محلی
`npm install && npm start`

## نحوه کار
- هر اکانت یک نشست مستقل دارد (پنجره ورود داخل خود اپ؛ رمز جایی ذخیره نمی‌شود، فقط کوکی نشست روی سیستم خودت).
- Claude و ChatGPT: مصرف و زمان ریست از endpointهای خود سایت خوانده می‌شود (غیررسمی؛ ممکن است با آپدیت سایت تغییر کند).
- Gemini و Figma: API مصرف برای اکانت شخصی وجود ندارد؛ شمارنده دستی با سقف و ریست خودکار.
- وقتی اکانتی که سهمیه‌اش پر شده بود دوباره آزاد شود، نوتیف ویندوز می‌آید.
