# انتشار افزونه در Chrome Web Store — قدم به قدم

برای Chrome کار می‌کند و Edge، Brave و بقیه‌ی مرورگرهای Chromium هم از همین فروشگاه نصب می‌کنند. همه‌ی متن‌های لازم آماده است: [store/LISTING.md](../store/LISTING.md).

## ۰. آماده‌ها (داخل همین ریپو)
- ✅ Manifest V3، آیکن‌های ۱۶/۳۲/۴۸/۱۲۸، توضیح کوتاه حداکثر ۱۳۲ کاراکتر
- ✅ اسکرین‌شات ۱۲۸۰×۸۰۰، تایل کوچک ۴۴۰×۲۸۰، مارکی ۱۴۰۰×۵۶۰ ← پوشه‌ی `store/`
- ✅ سیاست حریم خصوصی ← `PRIVACY.md`
- ✅ هدف واحد، توجیه مجوزها و متن لیستینگ ← `store/LISTING.md`
- ⬜ یک اکانت گوگل و **۵ دلار** (هزینه‌ی ثبت‌نام، فقط یک‌بار)

## ۱. تست محلی
1. در Chrome برو به `chrome://extensions`، **Developer mode** را روشن کن، **Load unpacked** را بزن و پوشه‌ی `extension/` را انتخاب کن.
2. در همان مرورگر وارد claude.ai / chatgpt.com شو و روی آیکن افزونه کلیک کن؛ باید اکانت‌ها و نوار مصرف بیایند. نشان روی آیکن، تنظیمات (زبان، فاصله‌ی بروزرسانی، اعلان) و بخش «درباره‌ی اپ دسکتاپ» را هم چک کن.
3. (اختیاری) اتصال به اپ دسکتاپ: اپ ← اتصال ← تب «افزونه مرورگر» ← کد را کپی کن ← در پاپ‌آپ افزونه بچسبان ← کارت «متصل» می‌شود.
4. بعد از نصب تازه، **صفحه‌ی خوش‌آمد** خودکار باز می‌شود (برای دیدن دوباره، افزونه را حذف و دوباره اضافه کن).

## ۲. ساخت فایل zip
فایل `AI-Usage-Monitor-Extension-<نسخه>.zip` را از Release گیت‌هاب بردار، **یا** خودت **محتویات** پوشه‌ی `extension/` را zip کن.
فایل `manifest.json` باید **ریشه‌ی** zip باشد (نه داخل یک پوشه).
برای هر آپلود بعدی، `version` در `extension/manifest.json` را **بالا ببر** (مثلاً `1.5.0` ← `1.5.1`)؛ نسخه‌ی مساوی یا کمتر رد می‌شود.

## ۳. ساخت اکانت توسعه‌دهنده (یک‌بار)
1. وارد [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) شو و با اکانت گوگل وارد شو (پیشنهاد: یک اکانت مخصوص انتشار).
2. توافق‌نامه را بپذیر و **۵ دلار** هزینه‌ی ثبت‌نام را بپرداز (فقط یک‌بار).
3. در بخش Account ایمیل تماس را ثبت و تأیید کن. اگر داشبورد خواست، **تأیید دو مرحله‌ای** گوگل را روشن کن. اگر درباره‌ی «trader» (قوانین اروپا) پرسید، مطابق وضعیت خودت جواب بده؛ یک پروژه‌ی رایگان و متن‌باز معمولاً non-trader است.

نکته: ناشر تازه در ابتدا حداکثر دو افزونه‌ی منتشرشده می‌تواند داشته باشد.

## ۴. آپلود
1. Dashboard ← **Add new item** ← فایل zip ← **Upload**.
2. صفحه‌ی آیتم با تب‌های سمت چپ باز می‌شود: Package، Store listing، Privacy، Distribution.

## ۵. تب Store listing
از `store/LISTING.md` پر کن:
- توضیح کوتاه و کامل، دسته‌ی **Productivity**، زبان
- آیکن ۱۲۸×۱۲۸، **حداقل یک** اسکرین‌شات ۱۲۸۰×۸۰۰ (تا ۵ تا)، **تایل کوچک ۴۴۰×۲۸۰ (اجباری)**، مارکی ۱۴۰۰×۵۶۰ (اختیاری)
- آدرس رسمی/سایت و پشتیبانی ← ریپوی گیت‌هاب و صفحه‌ی Issues آن

## ۶. تب Privacy
- **Single purpose** — متن را از `store/LISTING.md` بچسبان.
- **Permission justification** — برای هر مجوز یک کادر هست (`storage`، `alarms`، `notifications` و سه دسترسی میزبان). متن مربوط را بچسبان؛ بازبین‌ها می‌خوانند، پس دقیق باشد.
- **Remote code** — گزینه‌ی *No, I am not using remote code*.
- **Data usage** — آنچه افزونه مدیریت می‌کند را تیک بزن (ایمیل اکانت، داده‌ی مصرف خوانده‌شده از سایت‌ها) و سه تعهد را تأیید کن.
- **Privacy policy URL** — `https://github.com/Jolly-Panda-Works/ai-usage-monitor/blob/main/PRIVACY.md`

## ۷. تب Distribution
Visibility روی **Public** (یا **Unlisted** برای دور اول — فقط کسانی که لینک دارند نصب می‌کنند)، همه‌ی کشورها، رایگان.

## ۸. ارسال برای بررسی
1. **Submit for review** را بزن. در پنجره‌ی تأیید می‌توانی تیک «انتشار خودکار بعد از بررسی» را برداری تا خودت بعداً منتشر کنی (Defer publish).
2. منتظر ایمیل نتیجه بمان. معمولاً چند روز طول می‌کشد؛ افزونه‌های دارای دسترسی میزبان ممکن است بیشتر. وضعیت را در صفحه‌ی آیتم می‌بینی.
3. اگر **رد** شد: ایمیل را بخوان، دقیقاً همان مورد را اصلاح کن (دلایل رایج: توجیه مجوز مبهم، توضیحی که با رفتار افزونه نمی‌خواند، نبودن سیاست حریم خصوصی)، نسخه را بالا ببر و دوباره بفرست.

## ۹. بعد از انتشار
1. آدرس فروشگاه را کپی کن (`https://chromewebstore.google.com/detail/…/<شناسه>`).
2. در اپ دسکتاپ، فایل `src/main.js` را باز کن و `EXTENSION_STORE_URL` را با آن آدرس پر کن؛ بعد در «اتصال ← افزونه مرورگر» دکمه‌ی **Get it on Chrome Web Store** نمایش داده می‌شود. لینک را در README و صفحه‌ی خوش‌آمد هم می‌توانی بگذاری.
3. به `main` پوش کن — workflow خودکار نسخه‌ی جدید اپ را منتشر می‌کند.

## ۱۰. آپدیت‌های بعدی
کد را عوض کن ← `version` را در `extension/manifest.json` بالا ببر ← zip جدید را از Release بگیر (یا دوباره zip کن) ← داشبورد ← آیتم ← **Package** ← **Upload new package** ← **Submit for review**. بعد از تأیید، آپدیت خودکار به کاربران می‌رسد.

## اختیاری: Microsoft Edge Add-ons
